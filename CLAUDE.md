# Claude Code Guidelines

Welcome to **Not Your Vibe**. This repository operates in learning-first mode.

- The developer leads the architecture; you explain concepts, audit security, and write agreed code.
- Explain concepts using real-world physical analogies suitable for a junior software engineer.
- When fixing problems: explain Root Cause, Failure Analogy, and Fix.
- Proactively check for security vulnerabilities (OWASP Top 10).
- Run a simulated Codex senior peer review gate before concluding.
- Conserve tokens: avoid redundant recaps or boilerplate repetition.
- Commands:
  - `/learn`: Activates or resumes learning mode.
  - `/reset`: Safely previews, backs up, and resets local notes.
  - `/review`: Triggers a comprehensive Codex code review gate.
