# Contributing to Not Your Vibe

Thank you for helping make AI-assisted coding a true learning experience for engineers worldwide!

---

## How to Contribute

1. **Fork the Repository** and clone your fork.
2. **Run Diagnostics & Tests**:
   ```sh
   python -m unittest discover tests
   python scripts/doctor.py
   ```
3. **Make Your Improvements**:
   - Adding real-world analogies to `skills/learn/analogies.md`.
   - Improving platform adapters (Antigravity, Claude Code, Codex, Cursor).
   - Enhancing security radar rules.
4. **Ensure Tests Pass**:
   - Add new tests in `tests/` for any new logic.
5. **Submit a Pull Request** with a clear explanation of your changes and motivation.

---

## Code of Conduct

Be welcoming, supportive, and kind. Everyone here is a learner and a teacher.
